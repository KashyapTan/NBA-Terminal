## Honest provider and presentation limits

- Actual private ESPN future-plan ownership/eligibility/acquisition inputs were not inspected: Firefox timed out. The user's supplied diagnostics establish optional reconstruction gaps alongside complete official banked scoring; they do **not** establish whether today's free agents improve the team. No private-session success, hardcoded usage, roster transaction or authentication shortcut is claimed.
- NBA/ESPN public probes are point-in-time observations, separate from deterministic browser tests. Provider timeouts, schema changes, historical coverage and cached freshness remain visible. NBA CDN403 and successful1,274-row season fetch were separate requests; supported Stats primary/CDN fallback remain intact.
- Predictor/slate are uncalibrated heuristics. Rest comes from returned phase-specific team samples, not certified complete calendar history; roster selection is not a historical point-in-time membership guarantee. Standalone tools support30 standard NBA teams and Regular Season/Playoffs/Pre Season/All Star; other inherited phases are disclosed and require a supported selection.
- Player search uses bundled static directory metadata and can lag signings. Two observed player/season samples are shown at a time; exact absent-helper export formatting is not available. No invented trained model, percentile implementation equivalence, causal impact or betting confidence is asserted.
- Four-worker global NBA execution, existing bounded transport/backoff, in-flight dedup and explicit resource failures remain. Browser abort does not interrupt an already-running provider thread. Process-local caches are not shared across multiple server processes.
