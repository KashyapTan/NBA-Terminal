## Exact preserved formulas and deliberate corrections

Predictor: coerce finite non-null PTS; season mean, L5 only with ≥5 valid points else season, L10 only with ≥10 else season. Baseline `.45*season + .35*L5 + .20*L10`. Multiply by projected/mean valid MIN (positive mean required); missing/nonpositive MIN uses original factor 1 and explicitly labels an estimate. Defense `.10*(opponent DEF_RATING − unweighted league team mean)`; pace `.35*(opponent PACE − unweighted league team mean)*projected MIN/48`; rest ≥2 off-days +.4 otherwise −.4; home +.35 otherwise −.15; floor final at 0. DEF rating is points allowed per 100 possessions; pace is possessions per 48 minutes. Rest uses last returned **team** game, clips off-days to 0..5; its provenance is a returned sample, not guaranteed schedule completeness. Home requires the selected teams' actual scheduled matchup. Missing inputs stay null and prevent final total; user overrides have explicit estimate provenance. Original silent rest=3/home=away/league-average-opponent fallback removed. Team selection is context, not current roster verification. No probability, injury forecast, market line or calibrated wagering claim.

CV: require returned rows ≥window, take newest window **before** null removal, sample SD `ddof=1`, ≤1 valid value gives SD0. Mean≤0 or SD≤0 excludes row (including constant positive samples); these are not ranked first. Full-season traded-player histories retained. Actual valid stat count and requested window both displayed. Tier thresholds CV×100 <30 Elite, <50 Good, <70 Average, otherwise Variable. Nulls can reduce a full requested window to fewer valid stat observations; disclosed rather than silently claiming full valid count.

Defense: ascending known overall opponent FG%; missing overall values have no rank and Unknown tier, never best defense. Tiers 1..5 Elite, 6..15 Good, 16..20 Average, 21..25 Below Avg, 26+ Poor. Restricted area, non-RA paint, midrange, corner3, above-break3; supports both MultiIndex `FG_PCT` and `OPP_FG_PCT`. Left/right corner mean is **unweighted**, overriding any provider aggregate to retain the original convention. Both corners must be known; missing corner/zone or known zero attempts is unknown. Original missing-zone zero fill removed. League means are unweighted means of known team percentages, with denominators. No shot-quality adjustment.

Slate: actual date and phase filtered schedule, qualifying dashboard MIN≥25 and GP≥5. Require ≥5 returned historical log rows, then coerce/drop null PTS. L5 is newest up-to-five valid PTS; L10 when ≥10 valid else L5. Projection `.60*L5 + .25*L10 + .15*season_dashboard_PTS`; difference is projection minus season mean, include absolute difference≥3, sort descending absolute difference. Original “OVER/UNDER edge” names replaced by above/below season trend. Season dashboard and logs exclude selected day and later dates; this deliberately prevents retrospective look-ahead. Per-player fetch loops removed. Missing player samples counted separately from insufficient histories; a total log failure with a usable dashboard still counts qualified/missing players. Unavailable qualification dashboard cannot establish a count. Season is selected, not hardcoded.

## Public schema research and actual observations

Primary provider-maintained documentation inspected on 2026-11-01: [PlayerGameLogs endpoint/parameters/schema](https://github.com/swar/nba_api/blob/master/docs/nba_api/stats/endpoints/playergamelogs.md), [LeagueDashTeamShotLocations endpoint](https://github.com/swar/nba_api/blob/master/docs/nba_api/stats/endpoints/leaguedashteamshotlocations.md). Installed `nba_api 1.11.4` constructor signatures were inspected locally. Its static expected shot schema lists `FG_PCT`; actual public Opponent response returned MultiIndex `OPP_FG_PCT`. Both paths are tested. This distinction is why installed catalog metadata is not advertised as verified live support.

Original public observations: [raw endpoint log](evidence/v5_legacy/public-endpoints.txt), [six-service smoke](evidence/v5_legacy/live-service-smoke.txt). The manually selected Curry GSW/LAL matchup lacked a matching schedule home/away fact and correctly returned incomplete with `is_home` unknown. Picks48 files; installed catalog query matched1. These are unauthenticated public endpoint observations from that time, not a support guarantee or live private-account/browser inspection. Chromium screenshots below use prominently marked fixtures.

## Unavailable original sources and boundaries

[`archive/d.py`](../archive/d.py) imports `helper.formula` and `helper.percentile`; [`archive/c.py`](../archive/c.py) deletes generated charts. At this base `rg --files archive` finds only those two scripts and four guides, and no root/helper formula or percentile implementations. [README](../archive/guides/README.md), [percentile guide](../archive/guides/PERCENTILE_GUIDE.md), [complete guide](../archive/guides/COMPLETE_GUIDE.md), [quick-start](../archive/guides/quick_start.py) describe season/opponent mean/SD and quartiles/max/IQR, scatter/box plots and PNG exports. Exact helper interpolation, SD/zero/tie conventions and exports cannot be recovered. No trained/calibrated model artifact exists there. No archive execution/import or invented exact-parity claim is introduced. The retained six concrete standalone pages all have functional implementations; undocumented/absent helper algorithms remain unavailable. PLAYER owns expanded observed-sample profile/comparison measures.

Resource cache: worker-only, max64 entries, deduplicated fills, successful season/phase/resource/date values15min, schedule2min, catalog1hour, failures30sec cooldown. Existing injected runner adds30sec response cache and supplies pool/semaphore plus configured transport. Retrieval timestamps are exposed per resource; retrieval time does not establish provider statistic freshness. No import-time I/O. Provider identity/qualification schema loss is explicit resource failure; optional rates/zones stay unknown. Four workers remain the application's global limit, not a new unbounded executor. Cold resources share a lock, so requests may queue within that bound.
