# V8 daily lineup / forecast contract

Both rosters retain the V7 end-of-week contract: banked actual primitives plus exactly one season-rate contribution per remaining selected player-date. FG/FT use summed makes divided by summed attempts; lower turnovers wins. Plan net remains the complete after-minus-before team difference, including drops and displaced starts.

`baseline.daily_lineups` and `projected.daily_lineups` expose the actual selected decisions. Each remaining date has user and opponent rows containing `capacity`, `available_slots`, `focus`, and `players`. Each player includes ID, name, team abbreviation, observed eligible positions, assigned slot (null on bench), eleven primitive rates plus minutes, `playing`, `state` (`start`, `bench`, `locked`) and reason. Remaining `start` rows are exactly the forecast `starts` rows, which now also include `assigned_slot`. Locked rows reserve slots and display banked starters, but never add future production.

The current-roster baseline is the default actionable daily view. The optional after-plan view is explicitly hypothetical and applies the ordered moves on their effective dates. No independent browser ranking, fantasy transactions or lineup writes occur. Incomplete evidence stays labeled partial; absent rules do not become guessed position eligibility. Actual ESPN lineupSlotCounts and eligibleSlots supply legal positions; bench and IR do not count. Observed eligibleSlots are enforced exactly, including UTIL; generic UTIL matching is retained only for legacy domain inputs without ESPN eligibility provenance. More than ten active configured slots is a visible rules/capacity mismatch and blocks recommendations rather than silently discarding positions. Ten is the user's confirmed cap; their private league position rules remain unverified in this development environment.

Automatic focus now runs one nine-category discovery forecast and considers optimistic qualified-pickup potential only when acquisition capacity and an unprotected drop exist, preserves baseline cushion inclusion, then freezes five categories before the bounded plan search. The discovery estimate does not confer legality or qualify a move. All actionable baseline/plan lineups use the frozen focus. Both teams' lineups use the same focus categories, with opponent utility evaluated from its own side. Opponent starts are fixed across compared transaction scenarios. Explicit focus skips discovery. The former automatic 126-set/shared-nine-lineup policy is superseded; metadata states the actual selection source and one scored focus set.

Daily matching ranks independent marginal selected-category heuristic edges (weighted shooting and TO direction included), then uses augmenting position matching. Negative marginal utility can intentionally bench a player even with open capacity; `intentional_focus_bench` distinguishes this from `capacity_or_position`. This deterministic, bounded policy is not a proof of the best aggregate daily/weekly combination, nor is the bounded waiver beam search globally optimal. Existing materiality, core/protection, provider locks, acquisition usage and sample qualification guards remain enforced.

Refresh-only timestamp/source observations do not rank again in the browser. The saved backend decisions remain stable; meaningful roster, schedule, availability, focus or plan changes legitimately recompute. All-nine arithmetic remains in the collapsed technical view.
